# 코딩 툴 상점

파일 두 개로 돌아갑니다.

- `index.html` — 화면 전체 (상점, 장바구니, 주문, 결제, 충전금, 관리자)
- `server.py` — 상품·주문·충전금 저장, 결제 확인, 관리자 로그인 (Flask + SQLite)

## 시작하기

```bash
pip install -r requirements.txt
# .env 파일의 TOSS_CLIENT_KEY, TOSS_SECRET_KEY 를 내 키로 바꾸기
python server.py set-admin    # 관리자 비밀번호 정하기
python server.py              # http://서버주소:8780
```

- 상점: `http://서버주소:8780/`
- 관리자: 주소 뒤에 `#/admin` (상품 추가·수정·삭제, 사진 최대 8장, 주문 처리)
- 충전금: 주소 뒤에 `#/credit`

## 충전금 (계좌이체하면 자동 충전)

1. 손님이 연락처 + 비밀번호로 충전 계정을 만듭니다.
2. 충전 금액(`.env` 의 `CREDIT_OPTIONS`)을 고르면 토스페이먼츠 결제창에서 입금 전용 가상계좌가 발급됩니다.
3. 손님이 그 계좌로 이체하면 충전금이 자동으로 올라갑니다.
4. 주문할 때 "충전금으로 결제"를 누르면 바로 결제됩니다.
5. 관리자가 충전금 결제 주문을 취소하면 금액이 충전금으로 자동 환불됩니다.

### 입금 알림(웹훅) 등록 — 꼭 해 주세요

토스페이먼츠 개발자센터 → 웹훅 → 가상계좌 입금 알림(DEPOSIT_CALLBACK)에 아래 주소를 등록합니다.

```
https://내도메인/pay/toss/webhook
```

- 웹훅은 인터넷에서 접속되는 https 주소여야 합니다. `localhost` 로는 오지 않습니다.
- 웹훅이 없어도 손님이 충전금 화면을 열어 두면 15초마다 확인하고, "입금 확인" 버튼으로도 반영됩니다.
- 서버는 웹훅 내용을 그대로 믿지 않고, 시크릿 키로 토스에 다시 확인한 결과만 충전합니다. 같은 알림이 여러 번 와도 한 번만 충전됩니다.

### 알아 둘 점

- `test_` 로 시작하는 키는 실제 돈이 오가지 않습니다. 실제 키는 토스페이먼츠 가입·심사(사업자등록 필요) 후 발급됩니다.
- 입금된 돈은 내 계좌로 바로 오는 것이 아니라 토스페이먼츠 정산 일정에 따라 들어옵니다.
- 토스 연동 코드는 공개 문서를 기준으로 작성했고, 실제 토스 서버로는 아직 돌려 보지 못했습니다. 테스트 키로 충전 → 입금 처리까지 먼저 확인해 주세요.
- 충전금을 현금으로 돌려 달라는 요청(환불)은 직접 처리해야 합니다. 충전금 환불 규정을 사이트에 적어 두세요.
- `TOSS_SECRET_KEY` 는 절대 공개하지 마세요. `.env` 는 깃허브에 올리지 않습니다.

## 주문이 들어오면

결제가 끝난 주문은 관리자 화면 "결제 완료 · 구매 필요" 탭에 뜹니다. (`DISCORD_WEBHOOK_URL` 을 넣으면 디스코드 알림도 옵니다.)
주문을 열어 구매처 열기 → 배송 정보 복사 → 운송장 등록 순서로 처리합니다.

## 네이버페이 (선택)

가맹점 승인 후 받은 값을 `.env` 의 `NAVERPAY_...` 에 넣으면 결제 화면에 네이버페이 버튼이 추가됩니다.

## 공개하기 전에

- https 를 붙이고 `.env` 의 `BASE_URL` 을 실제 주소로 바꾸세요.
- 결제 키가 하나도 없으면 돈 없이 주문되는 "테스트 결제" 버튼이 나옵니다. 키를 넣으면 사라집니다.
- `shop.db` 와 `uploads/` 폴더를 주기적으로 백업하세요. 충전금 잔액이 여기에 들어 있습니다.
